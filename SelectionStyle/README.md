# SelectionStyle

SelectionStyle demonstrates how to customize the visual appearance of selected vector features in GeoKernel.

## Overview

It loads a sample vector layer, applies a normal layer style, then defines a distinct selection style so selected features are easy to identify on the map.

## GIS Workflow

This example shows:

- Setting default layer styling
- Configuring selected feature colors
- Making selection feedback visually clear
- Separating normal rendering from selection rendering
