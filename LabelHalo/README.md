# LabelHalo

LabelHalo demonstrates how to improve label readability with halo styling in GeoKernel.

## Overview

It prepares the required world sample data, loads a labeled country layer, and lets the user enable or disable text halos, choose a halo color, and adjust halo width at runtime. The example is useful for maps where labels need to remain readable over complex or high-contrast backgrounds.

## GIS Workflow

This example shows how to:

- Enable labels on a vector layer
- Configure label halo visibility
- Change label halo color
- Adjust label halo width
- Refresh label rendering after style changes
