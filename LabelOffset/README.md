# LabelOffset

LabelOffset demonstrates how to adjust label placement in GeoKernel.

## Overview

It prepares the required world sample data, loads a labeled country layer, and lets the user move labels horizontally and vertically with runtime offset controls. The example also includes a reset action so label placement can quickly return to the default position.

## GIS Workflow

This example shows how to:

- Enable labels on a vector layer
- Configure label offset X and Y values
- Update label placement interactively
- Reset label offsets
- Refresh label rendering after style changes
