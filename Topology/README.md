# Topology

Topology demonstrates a broad collection of geometry and topology operations with GeoKernel.

## Overview

It creates sample polygons, lines, arcs, and an intentionally invalid polygon entirely in memory, then displays them in a GeoKernel viewer. A toolbar lets the user run buffer, union, intersection, difference, symmetrical difference, convex hull, crossing, shape repair, arc connection, arc splitting, and spatial predicate operations while a details panel reports each result.

## GIS Workflow

This example shows how to:

- Create polygon, polyline, point, and arc geometry in memory
- Display source geometry with categorized styling
- Buffer polygon geometry
- Run union, intersection, and difference operations
- Calculate symmetrical difference and convex hull results
- Find crossings between line and polygon geometry
- Validate and repair an invalid polygon
- Connect and split arc geometry
- Evaluate spatial relationship predicates
- Visualize topology results interactively
