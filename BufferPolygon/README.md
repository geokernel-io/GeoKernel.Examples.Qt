# BufferPolygon

BufferPolygon demonstrates how to expand a polygon with a buffer generated by GeoKernel topology operations.

## Overview

It creates an irregular polygon entirely in memory, generates an outward polygon buffer with `GisTopology::MakeBuffer`, and displays the source geometry above the result. A runtime distance control rebuilds the buffer immediately, while a details panel compares source and result parts, vertices, geometry type, and geographic extents.

## GIS Workflow

This example shows how to:

- Create a polygon geometry in memory
- Build and close a polygon ring from vertices
- Initialize the GeoKernel topology engine
- Generate an outward buffer around a polygon
- Configure buffer distance and segment count
- Recalculate topology results interactively
- Compare source and result geometry extents
- Display the source polygon and buffer with separate styles
