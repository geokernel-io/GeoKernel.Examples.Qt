# GraduatedRenderer

GraduatedRenderer demonstrates how to style numeric attribute values with graduated classes.

## Overview

It loads California county data, classifies the POPULATION field with Natural Breaks, applies a selectable color ramp, and displays the generated population classes in a legend panel.

## GIS Workflow

This example shows:

- Creating a graduated symbol renderer
- Classifying numeric feature attributes
- Using Natural Breaks classification
- Switching color ramps at runtime
- Displaying graduated renderer legend items
