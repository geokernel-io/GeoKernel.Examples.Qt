# SimpleStyle

SimpleStyle is a focused GeoKernel example that demonstrates how to style vector layers directly with simple symbol settings.

## Overview

It loads polygon, line, and point data, then applies clear visual styling for each geometry type:

- Polygon fill and outline colors
- Line color and width
- Point color and size

## GIS Workflow

This example shows the quickest way to make raw vector data readable on the map without using categorized, graduated, or rule-based renderers.
