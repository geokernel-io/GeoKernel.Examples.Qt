# ClearRenderer

ClearRenderer demonstrates switching between a symbol renderer and the layer’s default style.

## Overview

It downloads the USA states sample data, loads the states layer, and applies a categorized renderer using the STATE attribute. The toolbar lets you reapply the categorized renderer or clear it, returning the layer to its default polygon style.

## GIS Workflow

This example shows how to:

- Load remote vector sample data
- Apply a categorized symbol renderer
- Clear an active symbol renderer
- Restore default layer styling
- Refresh the map after renderer changes
