# LabelFont

LabelFont demonstrates how to customize map label typography in GeoKernel.

## Overview

It prepares the required world sample data, loads a labeled country layer, and lets the user change the label font family, bold style, and italic style at runtime. The example keeps the map readable with halo styling while showing how label appearance can be updated without reloading the layer.

## GIS Workflow

This example shows how to:

- Enable labels on a vector layer
- Choose the label attribute field
- Set label font family
- Toggle bold and italic text styling
- Refresh the map after label style changes
