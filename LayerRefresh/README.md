# LayerRefresh

LayerRefresh demonstrates how to refresh a map layer after changing its style at runtime.

## Overview

It prepares the required California sample data, loads the California boundary layer, and provides toolbar actions to change the layer fill color, outline color, and fill opacity. The refresh action redraws the viewer so style changes can be applied and inspected interactively.

## GIS Workflow

This example shows the basic workflow for:

- Initialize a map viewer
- Download and load vector sample data
- Change layer style properties
- Refresh the map after style changes
- Inspect visual updates interactively
