# BasicLabel

BasicLabel demonstrates the basic label workflow for vector layers.

## Overview

It downloads the world sample data, loads country polygons, and enables labels using the selected attribute field. The side panel lets you toggle labels on and off, choose the label field, and adjust label font size while the map updates immediately.

## GIS Workflow

This example shows how to:

- Load remote vector sample data
- Enable labels on a vector layer
- Select the label attribute field
- Change label font size interactively
- Refresh map labels after style changes
