# CategorizedRenderer

CategorizedRenderer demonstrates how to style vector features by unique attribute values.

## Overview

It loads USA states data, builds a categorized renderer from the STATE field, assigns a distinct color class to each state category, and displays the generated categories in a legend panel.

## GIS Workflow

This example shows:

- Creating a categorized symbol renderer
- Styling features from an attribute field
- Using a color ramp for category colors
- Displaying renderer legend items
- Combining a styled vector layer with a map base layer
