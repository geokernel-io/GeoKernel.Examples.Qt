# HelloMap

HelloMap is the first GeoKernel example and demonstrates the basic workflow for displaying a map layer.

## Overview

It prepares the required sample data, loads a world boundaries shapefile, applies a clean professional map style, and zooms the view to the full map extent.

## GIS Workflow

This example shows the minimum GIS workflow needed to start working with GeoKernel:

- Initialize a map viewer
- Load vector data
- Apply a map style
- Zoom to the full map extent
- Present the result as an interactive world map
