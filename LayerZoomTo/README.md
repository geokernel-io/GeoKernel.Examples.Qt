# LayerZoomTo

LayerZoomTo demonstrates how to zoom the map view to a selected layer.

## Overview

It prepares the required California sample data, loads multiple city/county boundary layers, and lists them in a combo box. Selecting a layer zooms the viewer directly to that layer's extent, while the default option returns the map to the full extent.

## GIS Workflow

This example shows the basic workflow for:

- Initialize a map viewer
- Download and load multiple vector layers
- Populate a layer selection control
- Find a layer by name
- Zoom the viewer to a specific layer extent
