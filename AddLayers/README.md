# AddLayers

AddLayers is a basic GeoKernel example that demonstrates how to load and display multiple map layer types together.

## Overview

It prepares the required sample data, loads a raster backdrop, adds polygon country boundaries, adds city point features, applies distinct layer styles, and zooms the view to the combined map extent.

## GIS Workflow

This example shows the common GIS workflow for building a layered map with GeoKernel:

- Load raster data
- Load vector polygon data
- Load vector point data
- Style each layer appropriately
- Display all layers in a single interactive map view
