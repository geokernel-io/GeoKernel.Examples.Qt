# Measure

Measure demonstrates how to add distance and area measurement tools to a GeoKernel viewer.

## Overview

It prepares the required sample data, loads world boundaries and city point layers, adds a scale bar for spatial reference, and provides toolbar actions for pan, distance measurement, area measurement, clear, and full extent. The sample data is downloaded automatically on first run, so the example opens without requiring manual file setup.

## GIS Workflow

This example shows the basic workflow for:

- Initialize a map viewer
- Load vector data
- Add interactive measurement tools
- Measure distance and area on the map
- Clear measurements and return to full extent
