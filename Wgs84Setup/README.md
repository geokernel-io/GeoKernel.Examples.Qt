# Wgs84Setup

Wgs84Setup demonstrates how to configure a GeoKernel viewer and vector layer for the EPSG:4326 WGS 84 coordinate system.

## Overview

It prepares world boundary sample data, creates the WGS 84 coordinate system from its EPSG code, assigns it to both the source layer and viewer, and displays the map using longitude and latitude coordinates. The status bar reports the current mouse position in geographic degrees.

## GIS Workflow

This example shows how to:

- Download and load vector sample data
- Create the EPSG:4326 coordinate system
- Assign WGS 84 to a vector layer
- Configure a viewer to use geographic coordinates
- Set a longitude and latitude world extent
- Inspect map coordinates in decimal degrees
- Use standard map navigation tools
- Display an interactive WGS 84 world map
