# GeoKernel Qt Examples

Official Qt/C++ examples for the GeoKernel native GIS SDK.

## Requirements

- Windows 10 or later
- Qt 6 with MSVC
- CMake and Ninja
- A valid GeoKernel license

## Getting Started

Choose an example directory and follow its included build scripts or CMake configuration.
