# AddPointInteractive

AddPointInteractive demonstrates how to add point features by clicking on the map in GeoKernel.

## Overview

It prepares the required world sample data, loads a reference map layer, and creates an editable in-memory point layer. The user can activate the Add Point tool, click on the map to create new point features, pan the map, clear added points, and return to the full extent.

## GIS Workflow

This example shows how to:

- Create an editable in-memory point layer
- Activate the point digitizing tool
- Add point features interactively from map clicks
- Track feature count after edits
- Clear temporary edit features
- Refresh the map after editing operations
