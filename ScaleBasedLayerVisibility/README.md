# ScaleBasedLayerVisibility

ScaleBasedLayerVisibility demonstrates scale-dependent layer display.

## Overview

It downloads the world, USA states, and USA cities sample datasets, loads all layers after the data is prepared, and assigns each layer a visible scale range. As you zoom in and out, the side panel updates to show the current map scale and which layers are active at that scale.

## GIS Workflow

This example shows how to:

- Load multiple remote vector datasets
- Set minimum and maximum visible scale values
- Control layer visibility based on zoom level
- Monitor the current viewer scale
- Refresh UI state when scale or layer visibility changes
