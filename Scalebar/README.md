# Scalebar

Scalebar demonstrates how to add a dynamic map scale indicator to a GeoKernel viewer.

## Overview

It prepares the required sample data, loads a world boundaries shapefile, adds a scale bar control to the map view, and positions it in the bottom-right corner. The scale bar updates as the user zooms or pans, helping communicate real-world map distance at the current view scale.

## GIS Workflow

This example shows the basic workflow for:

- Initialize a map viewer
- Load vector data
- Add a map overlay control
- Display an interactive scale reference on the map
