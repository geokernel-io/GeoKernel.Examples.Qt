# OpenStreetMap

OpenStreetMap demonstrates how to add an online OpenStreetMap tile layer to a GeoKernel viewer.

## Overview

It creates a native map viewer, adds the built-in OpenStreetMap layer, and opens the map at a Web Mercator extent covering Europe. Toolbar actions provide zoom in, zoom out, full extent, rectangular zoom, and pan controls, showing the basic workflow for navigating an online tiled basemap.

## GIS Workflow

This example shows how to:

- Initialize a GeoKernel map viewer
- Add the built-in OpenStreetMap tile layer
- Work with a Web Mercator map extent
- Activate pan and rectangular zoom tools
- Zoom the viewer in and out programmatically
- Return to the layer's full extent
- Handle an online layer initialization failure
- Navigate an internet-based tiled basemap
