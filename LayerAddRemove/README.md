# LayerAddRemove

LayerAddRemove demonstrates how to add and remove map layers at runtime in a GeoKernel viewer.

## Overview

It lets the user add world boundaries, USA states, and USA city point layers from toolbar actions, with the required sample data downloaded automatically on first use. Layers can be removed individually or cleared all at once, showing how a viewer can manage its layer collection interactively.

## GIS Workflow

This example shows the basic workflow for:

- Initialize a map viewer
- Download and load vector sample data
- Add layers from user actions
- Remove individual layers by name
- Clear all map layers
