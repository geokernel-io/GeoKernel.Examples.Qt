# Classification

Classification demonstrates GeoKernel’s full thematic classification workflow.

## Overview

It downloads the California sample data, loads county polygons, and lets you build either categorized or graduated renderers from the layer’s attributes. The controls expose classification methods, class count, manual breaks, color ramps, ramp modes, reverse order, and render targets such as fill color, size, outline color, or outline width.

## GIS Workflow

This example shows how to:

- Load remote vector sample data
- Choose categorized or graduated rendering
- Select the classification field
- Configure classification methods and class counts
- Use manual breaks and interval-based methods
- Change color ramps and ramp modes
- Clear and reapply renderers interactively
